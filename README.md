## 云服务器版：泰拉瑞亚服务器搭建的完整步骤

开通之后你拿到的是控制台和文件管理器，真正的操作就五步，顺序别乱。

**第一步，决定世界从哪来。** 新开世界在 `serverconfig.txt` 里设 `autocreate`，1、2、3 分别对应小、中、大世界，首次启动自动生成。要把单机存档搬上去，先停服，用文件管理器把 `.wld` 传进 `worlds/` 目录，有 `.bak` 一并传，然后在 `serverconfig.txt` 里把世界路径指向它，重启。世界文件与本地客户端保持兼容，以后想拿回来下载就行。

**第二步，改 `serverconfig.txt`。** 这个文件是整个服务端的启动配置，管世界路径、最大人数、密码、MOTD、世界大小和难度。`maxplayers` 填 8–16 比较稳妥；`password` 留空就是公开服，设了密码玩家进服要输；`difficulty` 的 0–3 对应经典、专家、大师、旅行，**建世界之后无法更改**，开之前想好。这个文件只在启动时读取一次，保存完必须从控制台重启才生效，在运行中的服务器上改等于没改。

**第三步，放行端口。** 游戏走 7777/TCP，确认商家安全组和系统防火墙都没挡住。端口如果改过，以游戏界面显示的为准。

**第四步，告诉朋友怎么进。** 泰拉瑞亚没有公共服务器浏览器，游戏里的服务器列表搜不到你的服，这是设计如此，不是配置错了。玩家必须走“多人游戏 → 通过 IP 加入”，填服务器地址和端口。

**第五步，需要权限管理就装 TShock。** 原版服务端没有权限系统，谁进来都能拆家。TShock 会替换服务端二进制，提供账号、用户组、区域保护、防破坏和插件。装好之后进游戏执行一次 `/auth` 领取超级管理员账号，之后的管理命令都带斜杠：`/login`、`/user add`、`/region define`、`/reload`。

## 虚拟局域网版：房主当服务器怎么弄

这套方案的原理是给每台设备一个虚拟 IP（形如 172.16.x.x），让异地设备看起来像在同一个路由器下。工具用哪个都行，机制一样，下面以常见的蒲公英游戏版为例。

房主这边：装客户端 → 创建房间 → 在成员列表里记下自己的组网 IP → 启动游戏，选“开服并开始游戏”，建好世界停在世界里等队友。

队友这边：加入房间 → 也点联机 → 游戏里选“加入”→ 服务器地址填房主的组网 IP，端口填 7777。

顺序很关键。所有人先组网成功再启动游戏，房主先开服、队友后连接。反过来成功率会明显下降。另外几条容易被忽略：Windows 防火墙要同时放行游戏和组网客户端；部分安卓机型会杀后台导致断连；虚拟 IP 每次登录可能变化；装了 MOD 要所有人版本一致。

明确写在这里的限制：**免费房间 5 人（含房主）**，**房主关机世界就没了**，存档在房主电脑上，房主一退服务器就关；**Mac 暂不支持**，只有 Windows、Android、iOS 三端。房主的上行带宽和网络抖动会等比放大到每个队友身上，跨运营商绕路延迟直接翻倍。

## 面板服还是 VPS：先看你要不要独立 IP

雨云的游戏云分两种形态，选错会难受。

**面板游戏云**给的是网页控制台，内置 MCSManager，上传服务端、开服、备份、文件管理都在网页上点，带宽固定 50M 上行。它的 IP 是 NAT 端口映射，**没有独立公网 IP**，玩家连的是“域名 + 端口”。这一点对多数人无所谓，但你要做白名单、要固定地址对外宣传，就得考虑清楚。

**VPS 游戏云**是完整的 Linux 或 Windows 虚拟机，SSH / RDP 随便登，可选独立 IP，一台机器能同时跑多个服。装 tModLoader、想顺手跑个网站或机器人，都归到这一类。

判断很简单：第一次开服选面板服，十分钟能进游戏；要折腾环境或者一台机器干几件事，再上 VPS。

## 踩坑清单

- **世界回档**：泰拉瑞亚会在每个世界旁边写一个 `.bak`。停服后把 `world.bak` 改名成 `world.wld` 再启动就能回滚。确认恢复成功之前别删坏档。
- **更新前手动备份**：版本更新偶尔会改动世界数据，出问题再补救就晚了。
- **TShock 命令没反应**：基本是没登录。执行 `/login`，或者用首次启动时控制台打印的 `/auth` 码认领账号。
- **改了配置没生效**：`serverconfig.txt` 只在启动时读取，保存完必须重启。
- **难度改不了**：经典、专家、大师、旅行在建立世界那一刻就定死了。
- **列表里搜不到服务器**：泰拉瑞亚没有公共服务器浏览器，只能 IP 直连。
- **虚拟局域网方案卡顿**：先看房主的上行带宽，队友的体验上限由它决定。
